# Project Overview

## Motivation

TrueMatch explores whether everyday behavioural patterns can support partner discovery alongside conventional profiles. Activity categories make these inputs visible to users. This is an interaction concept, not evidence that those signals predict relationship success.

## Context and scope

A six-person university team developed the prototype for COMP90018, University of Melbourne (2025). The team product covers authentication, discovery, likes, chat, invitations and QR check-in. This repository provides the report, packaged Android build and demo link; it does not contain the application source or a reproducible development environment.

## Explore the experience

| Journey | What it demonstrates |
| --- | --- |
| **Create a profile** | Email/password authentication, registration and profile information |
| **Discover people** | Profile cards and per-category activity scores to make behavioural signals visible |
| **Express interest** | Likes and a dedicated likes list |
| **Start a conversation** | Chat lists and messaging integrated with Firestore |
| **Plan a date** | Invitations with a time, location and response status |
| **Check in** | Optional QR-based attendance confirmation |

The walkthrough is the quickest way to review the application without installing it.
